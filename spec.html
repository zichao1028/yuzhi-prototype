全局规则

合同标题

  • 用户界面不展示合同编号。合同标题 = 合同房间地址（楼栋地址 + 房号）以「、」连接，单行显示，超出以省略号截断；多房合同「共N间房」固定显示在截断区域外，始终可见。例：「中山南路2-14号301、中山南路2-14号302 共2间房」。
  • 引用另一份合同（来源合同、后续合同、房间合同链、结算单）时显示：合同标题 + 租期（起租日 至 到期/终止日）+ 承租人，并可点击进入该合同。

文案规则

  • 以合同为单位描述变化：原合同「已终止 · 终止原因：退租（房间 303）· 终止日」并链接后续合同；新合同「生效中 · 来源：退租（房间 303）后续签」并链接来源合同。
  • 禁止逐房迁移类表述；合同内房间只列该合同自己的房间。

模型

  • 一份合同 = 一组账单；合同生效后条款不改；结算单为独立单据。
  • 部分退租 / 换房 / 续租 = 终止原合同（结算到终止日）+ 开始新合同（新一组账单）+ 原合同应退抵扣新合同账单，余额现金退还或新合同待收。
  • 整单退租 = 终止原合同，不产生新合同，结算余额现金结清（无抵扣）。
  • 租约按房间查看（房间详情合同链）。

合同状态

  • 生效中：在租期内且未终止。
  • 已到期：已过到期日，尚未办理退租或续租；仍可办理退租 / 续租 / 换房。
  • 已终止：已办理退租 / 换房 / 续租并完成结算；不可再办理。

账单状态

  • 仅 4 种：待收（未收款）、部分收款（已收部分金额）、已收（已收清）、已完成（原合同结算后，全部账单统一完成）。
  • 原合同办理结算时，其全部账单（含未到期、未付、部分付）统一变为「已完成」，已收金额保留；剩余应收应退由结算单反映（《退租》退租结算、草案 §十）。
  • 不使用「已作废」：作废只用于重签的原合同（草案 §十三）。
  • 抵扣是收款方式（抵扣不计作实际收付），不是账单状态。

状态校验

  • 新增任何状态（合同、账单、房间、办理等）前，须对照本说明的模型定义校验：一份合同一组账单；合同变化以合同为单位（终止 / 开始）；收款方式、单据与状态分开，避免把收款方式或单据当作状态。

账单期间与金额（依据《租赁账单生成》）

  • 计租月：以起算日日号为基准，目标月份无该日号时取月末；当前计租月结束日为下一计租月开始日前一天；首尾日都计租。
  • 账单期间：按付款方式（付1压1 / 付3压1 / 付12压1）将连续计租月组成一期；首期结束日对齐自然月末（剩余房间合同默认对齐原合同付款节奏），末期截至合同结束日；相邻账单期间首尾相接。
  • 金额 = 完整计租月数 × 月租金 + 不足整月天数 × 月租金 ÷ 30，保留两位小数（第三位四舍五入）。
  • 押金 = 月租金 × 约定押金月数（示例均为压1）；月租金 = 合同各房间月租金之和。
  • 支付日：押金与第1期为合同开始日；第2期起为账单开始日期前 7 天。

收款与账单状态

  • 示例数据中支付日不晚于今天的账单已线下收清，标注逾期的除外；逾期 N 天 = 今天 − 支付日（待收 / 部分收款且支付日早于今天）。

入住状态

  • 合同生效 ≠ 已入住：每个合同房间单独记录「实际入住日」「实际退租日」，入住状态由此推导，与合同状态分开。
  • 未入住：尚无实际入住日。已入住：有实际入住日且未办理退租（合同已到期未退租仍为已入住；合同因续租 / 部分退租 / 换房终止时，未退出的房间在原合同上仍为已入住、无实际退租日，在后续合同沿用原实际入住日）。已退租：已办理退租（实际退租日 = 终止日）。
  • 实际入住日可晚于起租日；房间此前空置时可早于起租日（提前入住）；不得晚于今天。
  • 办理入住：生效中 / 已到期合同存在未入住房间时，「更多」中提供，选择房间与实际入住日（不晚于今天）。
  • 同一房间的入住区间（实际入住日 ~ 实际退租日或至今）不得与其他合同重叠（续接合同的同一入住除外）。

计租规则

  • 租金、押金按整份合同填写，不拆分到房间（草案 §四）；每期一张合同账单，押金一张。
  • 部分房间退租 / 换房：剩余房间合同、换入房间合同的月租金与押金由房东填写（草案 §八），不自动按房间求和。
  • 不足整月按 天数 × 月租 ÷ 30。
  • 剩余房间合同签约方式沿用原合同。

底部导航

  • 5 格：首页、房源、（中间预留位，无操作）、账单、我的。

合同详情

入口

  • 合同列表、账单页、房间详情合同链、来源 / 后续合同链接、结算单返回。

布局

  • 第 1 行：合同状态区，只显示合同状态（生效中 / 已到期 / 已终止），不显示来源等说明。
  • 第 2 行：合同标题；点击该行（复制 / 拨打按钮除外）弹出合同房间浮层：每间房地址、入住状态、实际入住日、实际退租日，不跳转页面。
  • 第 2 行：承租人姓名 + 手机号（脱敏），「复制」复制完整号码，「拨打」唤起电话。
  • Tab：合同 / 账单 / 承租人 / 入住人 / 办理记录（房间通过第 2 行浮层查看）；默认「合同」，支持 #b 等锚点直达。

入住人 Tab（依据《入住人管理》）

  • 按房间分组列出入住人：手机号（脱敏）、是否承租人本人、添加方式（手机号 / 不记名二维码）、状态（已生效 / 待同意）。可不填、可多名；未登记显示「未登记入住人」。
  • 生效中 / 已到期合同：添加入住人（选择对应房间；手机号添加立即生效；不记名二维码：仅生成并展示二维码，不产生入住人记录；拟入住人扫码后才出现该入住人，状态为待同意，经房东或承租人同意后生效）、同意（待同意）、删除（终止该人在对应房间的入住，不影响同房其他入住人）。文档未定义编辑，不提供。
  • 续租、部分房间退租：未退出房间的入住人在新合同继续入住；退出房间的入住人随退租终止；换入房间合同的入住人在新登记中重新确认。
  • 已终止合同：只读显示本合同期间登记的入住人。

已终止合同的房间

  • 房间浮层与房间合同链只显示「本合同入住期间」（实际入住日 至 本合同实际退租日 / 终止日；从未入住显示「未入住」），不显示当前入住状态。当前入住状态只在生效中 / 已到期合同与房间详情（随当前合同）显示。

  • 1 合同详情（含签约来源；有来源合同时显示来源合同标题 + 租期链接）→ 2 其他信息（含办理人）→ 3 终止信息（仅已终止，置于最后：终止原因、终止日、办理人、办理时间、结算单、后续合同链接）/ 到期信息（仅已到期，置于最后）。
  • 「办理人」为统一叫法，与合同列表筛选项「办理人」同一数据。

合同 Tab

结算单

依据

  • 草案 §十：按整份合同结算，期间为合同开始日至实际退租日 X（含当天）。

字段

  • 已收合计（原合同已收全部款项，含押金）、实际租金（完整计租月数 × 月租 + 不足整月天数 × 月租 ÷ 30，至 X；已到期合同超期部分同样计入，不单列）、随租金付的其他费用、扣款（金额 + 原因）。
  • 结算结果 = 已收合计 − 实际租金 − 其他费用 − 扣款；正数应退，负数应收（留在结算单线下收取，不转入新合同）。
  • 抵扣新合同账单：房东选择的账单与金额；线下退还 = 应退 − 抵扣，生成付款账单。

办理退租

入口

  • 生效中 / 已到期合同详情「退租」，合同自动带入。

步骤

  • 1 退租房间与实际退租日 X（草案 §六）：全选 = 全部退租；部分勾选 = 部分房间退租；单间合同直接全部退租。
  • 部分房间退租：2 剩余房间合同条款（X 次日至原到期日；月租金、押金由房东填写，预填原值可改；签约方式沿用）→ 3 结算单（其他费用、扣款可填）→ 4 抵扣（应退 > 0 时，房东选择新合同账单与金额）→ 5 确认。
  • 全部退租：2 结算单 → 3 确认（应退线下退还 / 应收线下收取）。

校验与边界

  • 未勾选房间、日期越界、到期日不晚于起租日、月租金 / 押金为空、扣款无原因：就地提示。
  • 每张抵扣 ≤ 该账单待收；抵扣合计 ≤ 应退；余额线下退还。

结果

  • 确认后进入办理结果页（原型不保存）；回放模式回到原合同。

办理换房

依据

  • 《出租业务模型调整》草案 §九：换房 = 一次退租 + 一次新的租客登记；一次只换一间。

入口

  • 生效中 / 已到期合同详情「更多 → 换房」。

步骤

  • 1 换出 1 间、选择同楼栋空置换入房间、换房日（已到期可晚于到期日，计超期占用）。
  • 2 剩余房间合同条款（原合同有剩余房间时；签约方式沿用原合同）；单间合同换房 = 整单退租，无剩余房间合同。
  • 3 换入房间合同条款：单独租客登记，房间仅换入房间，起租日默认换房日次日，到期日默认一年，月租金 / 押金由房东填写。
  • 4 结算单；5 抵扣：房东可选择剩余房间合同或换入房间合同的任意账单及金额（草案 §十一）；6 确认。

结果

  • 原合同已终止（终止原因「换房（换出 换 换入）」），终止信息链接剩余房间合同与换入房间合同；换入房间合同签约来源「新签（换房换入）」并链接换房原合同。

校验

  • 必须且只能换出 1 间；本楼栋无空置房间时不可继续；换入合同起租日须晚于换房日。

办理续租

入口

  • 生效中 / 已到期合同详情「续租」。

步骤

  • 1 新合同条款：房间同原合同；起租日 = 原到期日次日（已到期亦然，不计超期占用）；到期日默认一年。
  • 2 结算与抵扣：租金已结清，押金应退可抵扣。
  • 3 确认（终止原因「到期续租」）。

办理结果

展示

  • 原合同：已终止、原因、终止日、标题、租期、结算。
  • 新合同（部分退租 / 换房 / 续租）：生效中、来源、标题、条款、抵扣；整单退租显示「不产生新合同」。
  • 现金应退 / 应补。
