租客登记

  • 合同级月租金；选房不拆租金。流程：添加房源→签约方式→承租方→合同信息→核对账单。

TabBar 账单

  • 汇总仅总金额/已收/待收（付款侧已付/待付）；无批量。
  • 卡片标题含承租人（租金·N期·姓名）；地址次行（跨合同列表需要）。

合同详情

  • 页签：合同 / 账单 / 承租人 / 入住人（无办理记录）。复制、拨打保留。
  • 合同页：邀请绑定→入住人；合同详情字段仅文档已有（期间、月租金、押金、付款方式、支付时间、签约方式、房间、其他费用、业务状态）；其他信息含办理人、录入日、来源（新签/重签/续租关联）。
  • 账单页：标题仅「租金·N期 / 押金 / 结算应收 / 自定义名」，无承租人、无地址行。分区「待处理」「已完成」带笔数与合计。卡片：金额±、账期、应付日、N天后/逾期N天。
  • 账单页底栏：发票（待实现）、重置账单、添加账单、批量收款。
  • 底栏（合同/承租人/入住人）：更多（删除=软删除）、重签、换房（仅单房，多房不展示）、续租、退租。

退租

  • 整份合同结算，无选房、无部分退租。

重签

  • 预填租客登记；确认后新合同生效，原合同作废并关闭账单（不计入汇总）；新旧账单独立、不结转收付。重签时租期可与原合同重叠。

换房 / 续租

  • 换房仅单房。续租新开合同，起租=原结束次日。
