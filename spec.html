首页 / 我的

  • 入口：租客登记、合同、房源、账单、功能说明；重置示例数据。

租客登记

  • 顺序：①添加房源（模糊搜索，展示租赁状态）②签约方式③承租方④合同信息（合同级月租金、押金、其他费用）⑤去核对账单。
  • 月租金按整份合同填写，不再按房间拆分。押金默认 押M×月租金。房间只表示承租范围。
  • 账单预览：押金 + 各期「租金」账单项（及费用项）；可改金额/支付日、勾选已线下收款。

账单

  • 收款/付款切换；汇总仅 总金额/已收/待收（付款侧为总金额/已付/待付）。无批量选择、无笔数统计。
  • 卡片标题：租金·N期·承租人 / 押金·承租人；地址在次行。合同详情「账单」页签同款样式。
  • 状态：待收/部分收款/已收/已完成。

退租

  • 无部分退租。点退租直接进入整份合同结算：填实际退租日、其他费用、扣款；确认后全部房间退租、合同终止、账单已完成，生成结算单。
  • 结算 = 已收净额 − 实际租金（合同月租自开始日至退租日）− 其他费用 − 扣款。

换房 / 续租

  • 换房：仅单房合同。多房按钮禁用并提示「多房合同不支持换房」。单房：选退租日、新房间、新结束日 → 原合同结算终止 + 新合同登记（起租=退租次日）。
  • 续租：新开合同，起租=原结束日次日，原合同不自动终止。

计算规则

  • 计租月以开始日日号为锚；不足整月按 ÷30。分期按付N。

合同 / 房源

  • 详情页签：合同 / 账单 / 承租人 / 入住人（无办理记录）。第二行保留复制、拨打。
  • 租赁状态：已退租/待搬入/已入住。
