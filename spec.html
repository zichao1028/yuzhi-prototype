首页租客登记账单退租计算规则示例合同待分析原型决定

首页 / 我的

  • 入口：租客登记、合同管理、房源、账单、功能说明；「重置示例数据」。

租客登记

  • 入口：首页「租客登记」；房源中房间「租客登记」（预选该房）。表单草稿保存在 sessionStorage，进入子页面、账单预览后返回或刷新均保留；确认登记后清除。
  • 表单顺序：①添加房源——搜索框模糊搜索全部房间（地址/楼栋/房号部分匹配，不区分大小写，空格分隔多个关键字须全部命中），结果显示房间租赁状态（无租赁/待搬入/已入住），已选房间以可删除标签展示；本步不填租金。已有租赁的房间也可选择（租客登记：不能仅凭房间当前状态判断冲突），是否冲突在「去核对账单」时按租期冲突规则判断并提示原因。②签约方式：纸质合同/电子合同。③承租方信息：手机号*、姓名、证件号码、证件类型、证件照（子页面上传占位，返回显示张数）；姓名/证件类型/证件号码全填或全空，全空时证件照也须为空。④合同信息：开始时间*、结束时间*、付款方式 付N押M*、各已选房间月租金*、押金（整份合同，默认 押M×月租金合计，可改）、其他费用（名称、一次付清/随租金付、金额）、支付时间*、更多（子页面：合同扫描件≤10、补充条款、合同备注≤1000字）、紧急联系人（子页面，选填，填则完整）。
  • 「去核对账单」：校验通过进入账单预览页，否则在页面底部提示原因。
  • 账单预览页：单独列出押金账单及各期租金账单（期数、开始/结束日期、账单项、金额、支付日）；可修改账单项金额、支付日，可勾选整张账单「已线下收款」；返回修改不丢失表单与预览修改（表单内容变化时重新生成预览）。首期结束日期调整：未实现。
  • 确认登记：同时生成合同与全部账单（勾选的账单记为线下全额收款）→ 办理成功页（房间号、详细地址、月租金、合同租期、承租人、邀请二维码占位）→ 查看合同详情。

账单

  • 账单列表：收款账单/付款账单；状态页签；楼栋、类型筛选；汇总行；卡片显示支付日、逾期N天；批量选择待确认。
  • 收款账单状态：待收 / 部分收款 / 已收 / 已完成（合同结算后）。账单金额=账单项之和，可为 0（视为已收）。
  • 账单详情：账单项列表；待收/部分收款账单可增、改、删账单项（调整后金额不得低于已收）；已收、已完成不可调整。「确认收款」记录线下收款，可部分收款，不超过待收。
  • 付款账单（退给租客）：待付款 → 确认已线下付款 → 已完成。

退租

部分退租（选择部分房间，至少保留 1 间）

  • 不产生新合同；退租房间显示「已退租」，其入住人随之结束。
  • a) 包含实际退租日 X 的账单：新增账单项「{房号}退租」=−(该房本期租金 − 本期开始日至 X 的实际租金)。
  • b) X 之后开始的每期账单：新增「{房号}退租」=−该房本期全额租金。
  • c) 减免超过账单待收部分、或账单已收：账单不修改（已收账单永不修改），超出部分由房东选择：抵扣后续未收账单（按支付日顺序记「抵扣」，不计实际收付），或退给租客（生成付款账单）。
  • 预览列出每张受影响账单的调整前→后与账单项，减免金额和名称可修改；「确认办理」后跳转办理结果页列出全部变更。押金与其他费用不变。

最后一次退租（选择全部剩余房间；单间合同即此）

  • 结算 = 已收合计（线下收款，含押金；减去已退给租客的金额）− 实际租金（各房从开始日到各自退租日）− 其他费用（随租金付按月计至 X + 一次付清全额，可改）− 扣款（可填，需原因）。
  • 结果 >0 应退 → 生成付款账单；<0 应补 → 生成收款账单「结算应收」。合同变为已终止，原有账单全部「已完成」，生成结算单。

计算规则（租赁账单生成）

  • 计租月以合同开始日的日号为基准，目标月无该日取月末。
  • 区间租金 = 完整计租月数 × 月租 + 不足整月天数 × 月租 ÷ 30（含首尾日），保留 2 位小数。
  • 分期：每 N 个计租月一期，末期截止合同结束日。支付日：押金与第1期为开始日；其后为期开始日前 N 天，或期开始月份的固定日。

示例（与测试一致）

  • 张三 · 中山南路2-14号301/302/303，月租 1000/1000/1300，物业费 100/月随租金付，付3押1，押金 3300，2026-01-01~12-31。第4期（10-01~12-31）=3000+3000+3900+300=10200，已收 5000 后调整加维修费 50 → 10250。
  • 301 于 2026-11-15 退租：本期实际 = 1 个计租月 + 15 天 = 1000+500 = 1500，减免 3000−1500 = 1500 ≤ 待收 5250 → 第4期 10250 → 8750。
  • 302、303 于 2026-11-30 退租（最后一次）：已收 3300+3×10200+5000 = 38900；实际租金 301 10500 + 302 11000 + 303 14300 = 35800；物业费 11×100 = 1100；结算 38900−35800−1100 = 应退 2000。
  • 王五（示例已部分退租）：306 于 2026-08-15 退租，8 月账单已收 → 减免 1200−600 = 600 抵扣 9 月账单；9 月起各期 306退租 −1200。
  • 李四 501 月租 1500，2026-10-17 退租、扣款 200（清洁）：已收 1500+8×1500=13500，实际租金 7个月+17天=11350 → 应退 1950。

合同 / 房源

  • 合同详情：第1行合同状态（生效中/已到期/已终止；文档未定义合同状态，沿用既有确认；开始日前也显示生效中）；第2行合同标题（点开房间弹窗）；页签 合同/账单/承租人/入住人/办理记录；卡片顺序 合同详情→其他信息→终止/到期信息。
  • 租赁状态（prd-租客登记）：已退租 / 待搬入（未到开始日，或已到开始日但前租客未退租）/ 已入住；实际入住时间独立记录（「记录实际入住时间」）。房源页显示该房当前未退租租赁的租赁状态，无则「无租赁」。入住人：按房间分组；手机号添加（立即生效）、二维码添加（仅展示二维码）、同意、删除。

原型自行决定（文档未说明）

  • 退租文档未限定合同开始前能否退租：原型允许（实际退租日不早于合同开始日）。
  • 账单金额为 0（全额退租减免）视为已收。
  • 结算时一次付清的其他费用全额计入；随租金付费用按月计至实际退租日；结算的「其他费用」可手动修改。
  • 抵扣按支付日先后依次冲抵后续未收账单（含押金账单以外的租金账单，押金账单若未收也参与），不足部分生成付款账单。
  • 登记时不录入入住人，登记后在入住人页签添加。
  • 合同标题：同一楼栋为「楼栋+房号、房号」，跨楼栋为各房完整地址以「、」连接，均显示共N间房。
  • 证件类型：文档未给选项，改为文本输入。
  • 押金、其他费用按整份合同填写（用户既有规则）；biz-租客登记 写为「按房间分别明确」，待确认。
  • 示例房源扩充为 4 个楼栋 23 间（新增 张江Lofts B栋 10 间）用于展示搜索。
  • 部分退租的 X 须在合同期内；最后一次退租的 X 不早于已退房间的退租日，已到期合同可晚于结束日但不晚于今天。
