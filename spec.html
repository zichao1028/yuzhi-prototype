全局规则

合同标题

  • 用户界面不展示合同编号。合同标题 = 合同房间地址（楼栋地址 + 房号）以「、」连接，单行显示，超出以省略号截断；多房合同「共N间房」固定显示在截断区域外，始终可见。例：「中山南路2-14号301、中山南路2-14号302 共2间房」。
  • 引用另一份合同（来源合同、后续合同、房间合同链、结算单）时显示：合同标题 + 租期（起租日 至 到期/终止日）+ 承租人，并可点击进入该合同。

文案规则

  • 以合同为单位描述变化：原合同「已终止 · 终止原因：退租（房间 303）· 终止日」并链接后续合同；新合同「生效中 · 来源：退租（房间 303）后续签」并链接来源合同。
  • 禁止逐房迁移类表述；合同内房间只列该合同自己的房间。

模型

  • 一份合同 = 一组账单；合同生效后条款不改。
  • 部分退租 / 换房 / 续租 = 终止原合同（结算到终止日）+ 开始新合同（新一组账单）+ 原合同应退结转抵扣新合同账单，余额现金退还或新合同待收。
  • 整单退租 = 终止原合同，不产生新合同，结算余额现金结清（无结转）。
  • 租约按房间查看（房间详情合同链）。

合同状态

  • 生效中：在租期内且未终止。
  • 已到期：已过到期日，尚未办理退租或续租；仍可办理退租 / 续租 / 换房。
  • 已终止：已办理退租 / 换房 / 续租并完成结算；不可再办理。

账单状态

  • 仅 4 种：待收（未收款）、部分收款（已收部分金额）、已收（已收清）、已作废（合同终止后未起租且未收款的期次）。
  • 合同终止不改变已收账单：终止前已收清的账单保持「已收」；终止后未起租 / 未收款的账单变为「已作废」。
  • 结转抵扣是收款方式，不是账单状态：新合同账单被原合同应退抵扣后，按收款金额记为「已收」或「部分收款」，并在收款方式中注明「结转抵扣（原合同应退）」。
  • 结算单是独立单据，引用原合同账单与收款计算应退 / 应补，不改变任何账单状态。

状态校验

  • 新增任何状态（合同、账单、房间、办理等）前，须对照本说明的模型定义校验：一份合同一组账单；合同变化以合同为单位（终止 / 开始）；收款方式、单据与状态分开，避免把收款方式或单据当作状态。

计租规则

  • 部分退租 / 换房新合同的默认月租 = 新合同各房间月租之和（每个房间有自己的月租），可修改；默认押金 = 默认月租。续租默认沿用原月租。
  • 整月按月租；不足整月按 月租 ÷ 当月天数 × 天数，保留两位小数。
  • 超期占用：已到期合同办理退租（或换房）时，原到期日次日至退租日按原日租金计「超期占用」，从应退中扣除；已到期合同续租时新合同自原到期日次日起算，不计超期占用。

首页

目的

  • 工作台入口。

展示

  • 合同管理（生效中 / 已到期 / 已终止份数）、房源、账单、功能说明入口。

合同列表（合同管理）

入口

  • 首页「合同管理」。

卡片字段

  • 第 1 行：合同标题（见全局规则：地址、截断、共N间房）。
  • 第 2 行左：「起租日 至 到期日 | 承租人」，已终止合同显示实际终止日；右：合同状态标签（生效中 / 已到期 / 已终止）。

筛选与排序

  • 楼栋：全部楼栋（默认）/ 各楼栋地址，单选。
  • 合同状态：全部状态（默认）/ 生效中 / 已到期 / 已终止。
  • 筛选（底部面板）：处理人、签约方式、付款方式（多选）；起租日范围、到期日范围。重置 / 确定；关闭或点遮罩不生效；按钮显示已选条件数。
  • 排序：按录入日期降序（默认）/ 按起租日升序 / 按起租日降序 / 按到期日升序。
  • 下拉以浮层显示在吸顶筛选栏下方并遮罩列表，不推动列表；点遮罩关闭。

空状态

  • 「无符合条件的合同」。

跳转

  • 点卡片 → 合同详情。

合同详情

入口

  • 合同列表、账单页、房间详情合同链、来源 / 后续合同链接、结算单返回。

布局

  • 第 1 行：合同状态区（生效中 / 已到期 / 已终止 + 说明）。
  • 第 2 行：合同标题；承租人姓名 + 手机号（脱敏），「复制」复制完整号码，「拨打」唤起电话。
  • Tab：合同 / 账单 / 承租方 / 多房列表(N) / 办理记录 / 审批记录；默认「合同」，支持 #b 等锚点直达。

多房列表

  • 每个房间显示地址与房间月租。

合同 Tab

  • 已终止：顶部终止信息卡（终止原因、终止日、结算单、后续合同或「整单退租，无后续合同」）。已到期：顶部到期信息卡（到期日、已超期天数、超期占用说明）。
  • 合同详情：合同周期、实际终止（已终止）、计划退租、常规押金、付款方式（付1押1 / 付3押1）、租金单价、总租金（月租 × 合同月数）、免租天数、支付时间、委托模式、房源签署类型（单房源 / 多房源签署，按房间数）、业务状态（在租中 / 已到期未退 / 已退租 / 已续租）、查看PDF。
  • 其他信息：签约人、签约时间、录入人、录入时间、合同维护人、合同归属部门、签约来源（新签 / 续签 / 退租后续签 / 换房后续签）、签约方式、租客来源；有来源合同时显示来源合同（标题 + 租期，可点击）。

其他 Tab

  • 账单：仅本合同账单；已终止显示「查看结算单」。
  • 承租方：姓名、手机号、证件、紧急联系人。
  • 多房列表(N)：本合同房间地址，点击进入房间详情。
  • 办理记录：录入、来源（后续签自哪份合同）、终止（办理类型、原因、后续合同）；已终止合同可「回放办理过程」。
  • 审批记录：合同录入审批（占位）。

底部操作栏

  • 显示条件：合同状态为生效中或已到期；已终止不显示。
  • 退租（主要）、续租（次要）、更多（底部面板：换房、查看PDF、取消；点遮罩关闭）。

结算单

字段

  • 原合同（标题 + 租期）、终止原因、终止日。
  • 结算：实际租金、已收租金、租金应退 / 应补、超期占用（如有）、押金应退、合计应退。
  • 结转到后续合同（标题 + 租期）：逐项与合计；整单退租无此块。
  • 现金应退承租人 = 合计应退 − 结转合计。

办理退租

入口

  • 生效中 / 已到期合同详情「退租」，合同自动带入。

步骤

  • 1 退租房间与退租日：多房合同勾选房间——全选 = 整单退租，部分 = 部分退租；单间合同直接整单退租（房间锁定）。退租日：生效中须在租期内；已到期可晚于到期日（至今天），超出部分计超期占用。
  • 整单退租：2 结算（现金结清，无结转）→ 3 确认（原合同将终止，不产生新合同）。
  • 部分退租：2 新合同条款（保留房间；起租日 = 退租日次日；到期日默认原到期日，已到期合同默认一年；月租 / 押金 / 付款方式可改）→ 3 结算与结转 → 4 确认（原合同将终止；将开始新合同）。

校验与边界

  • 未勾选房间、日期越界、到期日不晚于起租日、月租为空：就地提示，不可下一步。
  • 实际租金 + 超期占用大于已收时显示应补；现金显示「承租人应补」。
  • 结转不超过合计应退，超出为新合同待收。

结果

  • 确认后进入办理结果页（原型不保存）；回放模式回到原合同。

办理换房

入口

  • 生效中 / 已到期合同详情「更多 → 换房」。

步骤

  • 1 换出 1 间、选择同楼栋空置换入房间、换房日（已到期可晚于到期日，计超期占用）。
  • 2 新合同条款：保留房间 + 换入房间。
  • 3 结算与结转；4 确认（终止原因「换房（换出 换 换入）」）。

校验

  • 必须且只能换出 1 间；本楼栋无空置房间时不可继续。

办理续租

入口

  • 生效中 / 已到期合同详情「续租」。

步骤

  • 1 新合同条款：房间同原合同；起租日 = 原到期日次日（已到期亦然，不计超期占用）；到期日默认一年。
  • 2 结算与结转：租金已结清，押金应退可结转。
  • 3 确认（终止原因「到期续租」）。

办理结果

展示

  • 原合同：已终止、原因、终止日、标题、租期、结算。
  • 新合同（部分退租 / 换房 / 续租）：生效中、来源、标题、条款、结转；整单退租显示「不产生新合同」。
  • 现金应退 / 应补。

房源

展示

  • 按楼栋地址列出房号，点击进入房间详情。

房间详情

展示

  • 房间地址；当前合同（生效中或已到期，标题 + 租期，可点击）或「空置」。
  • 合同链：涉及本房间的合同按承租人分组、按起租日排列，每条：合同状态、合同标题 + 租期、来源或终止原因。

空状态

  • 暂无合同。

账单

展示

  • 每份合同一张卡片：合同标题、承租人、待收笔数与金额、合同状态。

跳转
