登记账单合同详情退租重签换房续租

租客登记

  • 合同级月租金；选房不拆租金。流程：添加房源→签约方式→承租方→合同信息→核对账单。

TabBar 账单

  • 汇总仅总金额/已收/待收（付款侧已付/待付）；无批量。
  • 卡片标题含承租人（租金·N期·姓名）；地址次行（跨合同列表需要）。

合同详情

  • 页签：合同 / 账单 / 承租人 / 入住人（无办理记录）。复制、拨打保留。
  • 合同页：邀请绑定→入住人；合同详情字段仅文档已有（期间、月租金、押金、付款方式、支付时间、签约方式、房间、其他费用、业务状态）；其他信息含办理人、录入日、来源（新签/重签/续租关联）。
  • 账单页：标题仅「租金·N期 / 押金 / 结算应收 / 自定义名」，无承租人、无地址行。分区「待处理」「已完成」带笔数与合计。卡片：金额±、账期、应付日、N天后/逾期N天。
  • 账单页底栏：发票（待实现）、重置账单、添加账单、批量收款。
  • 底栏（合同/承租人/入住人）：更多（删除=软删除）、重签、换房（仅单房，多房不展示）、续租、退租。

退租

  • 点退租弹出「退房操作」：同时结账（推荐）/ 先退房后续结账 / 取消。
  • 先退房：实际退房时间*、原因（到期/违约/转租/协议退租）、退后状态（空房可租/锁房/维修/脏房）、备注、照片；无金额。立刻释房，账单不标已完成；结果「去结算」。
  • 退租结算单：应退/扣除为跳转子页（退款/扣款明细表可编辑）；主单只读汇总；无收款人。付款默认「生成待收账单」/「线下收款」+支付时间/方式/经办人；线上/申请第一版不实现。
  • 合同详情另有「物业交割」「设备账户」页签：第一版不实现。
  • 房源支持独栋按层生成房号、预览调整、新增/编辑房间、锁房与价格配置。

重签

  • 预填租客登记；确认后新合同生效，原合同作废并关闭账单（不计入汇总）；新旧账单独立、不结转收付。重签时租期可与原合同重叠。

换房 / 续租

  • 换房仅单房，原结算应退可勾选抵扣新账单，按押金、第1期、第2期顺序执行；不可跳过未结清前序账单。续租新开合同，起租=原结束次日；原押金须付清，生成押金应退并自动抵扣新押金。其他欠款留原合同；余额保留待收/待付。

房源与房间

  • 列表按楼栋分组，房间卡展示房号、状态、配置月租、租客/到期日或空置天数；支持状态、楼层筛选。旧数据无空置起点时从迁移日计，不推测历史空置。
  • 独栋：名称、总层高、每层间数、选填地址；一位前缀、去4、至少4位。去4只跳过房间尾号含4的编号，不跳4楼。生成后可调某层间数、改号、删房，至少保留一间。
  • 房号沿用原型的全库唯一引用；不同楼栋同号需用前缀区分。编辑房号会同步合同及入住人关联。
  • 状态：空房可租/已出租/锁房。在租优先显示已出租，同时显示锁定标记。锁房禁止登记；脏房/维修仅作状态标记。
  • 房间基准月租、押N或固定押金、默认付1；登记时仅建议填入，合同级月租由房东确认。房间详情含合同列表与空态。

流水与账单状态

  • 合同账单区、收款/付款账单详情均可进入流水，支持按合同筛选。支付时间、应支付日、合同、类型、方式、现金净额、经办可查看。
  • 收款状态统一为待收、已完成、已作废；部分到账仍为待收；已关闭账单待收为0。付款支持部分付款，汇总按实际已履行金额计算。
  • 抵扣生成来源/目标两笔关联流水，履行金额相等、方向相反，现金净额为0，不冒充线下收付款。历史记录迁移流水时按来源键去重。

本轮简化与对照边界

  • 根据本轮P0，续租/换房在办理提交时执行抵扣；需求文档要求电子合同生效、续租到起租日才履行，原型尚无签约异步状态机与定时衔接。
  • 独栋地址仅文本，不实现寓小二/房源文档中的地图经纬度、照片视频、公区、产权/户号、批量定价等。
  • 寓小二PC内嵌表格/侧栏在移动端采用房间卡与编辑、价格、合同详情子页。本轮未获取登录后的寓小二业务页面，对照依据为提供的文档与盘点，不声称逐屏核验。
  • 续租押金金额自动按原已付押金计算，仅抵扣新押金；人工调整结算金额、将余额另编排到租金等完整能力后置。
