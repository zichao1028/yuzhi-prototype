# 寓智云控 房东端 · 低保真原型（产品原型）
在线：https://zichao1028.github.io/yuzhi-prototype/ · 功能说明（PRD）：[spec.html](https://zichao1028.github.io/yuzhi-prototype/spec.html)
本地：`python3 -m http.server 8080 --directory .`（纯 HTML/CSS/JS，无构建；数据在 data.js）

低保真线框：灰阶、简单框线，仅表达信息结构与交互，不代表视觉设计。每页右上「功能说明」跳转 spec.html 对应章节。

## 模型
- 一份合同 = 一组账单；合同生效后条款不改。
- 部分退租 / 换房 / 续租 = 终止原合同（结算到终止日）+ 开始新合同（新一组账单）+ 应退结转抵扣新合同账单。
- 租约按房间查看（房间详情的合同链），无独立租约页、无独立账单。
- 合同状态：生效中 / 已到期 / 已终止。

## 文案规则
- 以合同为单位描述：「合同 H1：已终止 · 终止原因：退租（房间 303）· 后续合同 H2」「合同 H2：生效中 · 来源：合同 H1 退租（房间 303）后续签」。
- 禁用词：转至、已转至H2、房间挂靠。

## 页面
index 首页 · contracts 合同列表（楼栋 / 合同状态 / 筛选 / 排序，浮层不推动列表）· contract-h1…h12 合同详情（生效中底部办理操作）· bills-h* 合同账单 · settlement-h1/h3/h6/h10 结算单 · checkout / swap / renew-flow.html?c=合同号 办理流程 · result 办理结果 · rooms 房源 · room-* 房间详情 · bills 账单 · me 我的 · spec 功能说明。

## 场景数据（楼栋：中山南路2-14号 / 漕溪北路88弄5号 / 虹桥路1号3号楼）
- H1→H2 退租 303（04-15）：实际租金 10,500，应退 10,500，结转 7,000，现金退 3,500。
- H3→H4 换房 306 换 307：押金 2,000 结转 H4 押金。H6→H7 到期续租：押金 1,800 结转。
- H10 到期退租；H12 已到期未办理；其余为生效中。
