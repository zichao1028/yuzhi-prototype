# 寓智云控 房东端移动原型（纯 HTML/CSS/JS，无构建）
在线：https://zichao1028.github.io/yuzhi-prototype/ · 本地：`python3 -m http.server 8080 --directory .`

## 模型
- 一份合同 = 一组账单；合同生效后条款不改。
- 部分退租 / 换房 / 续租 = 终止原合同（结算到终止日）+ 开始新合同（新一组账单）+ 应退结转抵扣新合同账单，余额现金退或待收。
- 租约按**房间**查看：房间详情列出涉及该房间的合同链（按承租人租约分组），租约本身无账单。
- 旧账单只在旧合同页，新账单只在新合同页。

## 文案规则
- 以合同为单位描述：「合同 H1：已终止 · 终止原因：退租（房间 C）· 终止日 2026-04-15 · 后续合同 H2」「合同 H2：生效中 · 来源：合同 H1 退租（房间 C）后续签」「终止原因：换房（F 换 G）」「到期续租」。
- 合同内房间列表只列该合同的房间，不显示逐房迁移状态。
- 禁用词：转至、已转至H2、房间挂靠。

## 页面
- index.html 首页：合同管理 / 房源 / 账单入口
- contracts.html 合同管理：楼栋、合同状态下拉；筛选面板（处理人、签约方式、付款方式、起租日范围、到期日范围，重置/确定）；排序（录入日期降序默认、起租日升/降序、到期日升序）。均在 data.js 上实时生效。
- contract-h1…h11.html 合同详情；生效中合同底部操作栏：办理退租（多房时）、办理换房、办理续租；合同房间可点进房间详情。已终止合同有终止信息、结算单链接、办理记录（可回放办理过程）。
- bills-h1…h11.html 各合同账单；settlement-h1/h3/h6/h10.html 结算单。
- checkout-flow / swap-flow / renew-flow.html?c=合同号：从合同发起，合同预填，无选择合同步骤；分步、校验、按日实时计算结算与结转。对已终止合同 H1/H3/H6 为回放（确认后回到该合同）；对生效中合同确认后到 result.html（展示终止的原合同与新合同，不保存）。
- rooms.html 房源（按楼栋）；room-*.html 房间详情（当前合同 + 租约合同链）。
- bills.html 账单（按合同汇总待收，进入各合同账单）；me.html 占位。

## 场景数据
- H1→H2（退租 C，04-15）：实际租金 10,500；已收 18,000；应退 7,500+3,000=10,500；结转 H2 押金 2,000 + 04-16~06-30 租金 5,000 = 7,000；现金应退 3,500。
- H3→H4（换房 F 换 G，05-31）：应退押金 2,000，结转 H4 押金（2,200，余 200）；现金 0。
- H6→H7（到期续租）：押金 1,800 结转 H7 押金（1,900，余 100）。
- H10 到期退租，押金 1,500 现金退还。H5/H8/H9/H11 为普通生效中合同。
