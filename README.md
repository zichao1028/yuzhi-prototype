# 寓智云控 房东端 · 低保真原型（产品原型）
在线：https://zichao1028.github.io/yuzhi-prototype/ · 功能说明（PRD）：[spec.html](https://zichao1028.github.io/yuzhi-prototype/spec.html)
本地：`python3 -m http.server 8080 --directory .`（纯 HTML/CSS/JS，无构建；数据在 data.js）

低保真线框：灰阶、简单框线，仅表达信息结构与交互，不代表视觉设计。每页右上「功能说明」跳转 spec.html 对应章节。

## 模型
- 一份合同 = 一组账单；合同生效后条款不改。
- 部分退租 / 换房 / 续租 = 终止原合同（结算到终止日）+ 开始新合同（新一组账单）+ 应退结转抵扣新合同账单。
- 租约按房间查看（房间详情的合同链），无独立租约页、无独立账单。
- 合同状态：生效中 / 已到期 / 已终止。生效中与已到期可办理退租/续租/换房。
- 退租：全选房间 = 整单退租（不产生新合同，现金结清）；部分 = 关旧开新。已到期退租超期部分按原日租金计超期占用。
- 界面不展示合同编号；合同标题 = 房间地址「、」连接，单行截断，多房「共N间房」常显；引用其他合同显示标题 + 租期。

## 文案规则
- 以合同为单位描述：原合同「已终止 · 终止原因：退租（房间 303）」+ 后续合同链接；新合同「生效中 · 来源：退租（房间 303）后续签」+ 来源合同链接。
- 禁用词：转至、已转至H2、房间挂靠。

## 页面
index 首页 · contracts 合同列表（楼栋 / 合同状态 / 筛选 / 排序，浮层不推动列表）· contract-h* 合同详情（状态区、标题+承租人、Tab：合同/账单/承租方/多房列表/办理记录/审批记录；生效中/已到期底部：更多(换房)/续租/退租） · settlement-h1/h3/h6/h10 结算单 · checkout / swap / renew-flow.html?c=合同号 办理流程 · result 办理结果 · rooms 房源 · room-* 房间详情 · bills 账单 · me 我的 · spec 功能说明。
